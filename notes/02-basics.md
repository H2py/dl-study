## 배우지 않은 사람에게 설명한다면
숫자 0,1 이미지가 주어졌을 때 무엇이 0 or 1인지를 구분한다고 해보자.  
사람은 숫자를 보고 너무나도 쉽게 이것이 0인지 1인지 쉽게 구분한다.  
높이가 더 긴 0, 너비가 더 넓은 0, 가운데에 선이 그어진 0처럼 아무리 모양이 달라지더라도 우리는 이를 0으로 인식한다.   

인지적 마찰 없이 물체를 인식하기 때문에 '무언가를 본다'는 것이 별 것 아닌 일인 것 같지만, 이를 컴퓨터를 통해, 0을 구분하도록 모든 규칙을 나열하는 것은 상당히 어려운 작업이 될 것이다.


그럼 컴퓨터는 어떻게 물체를 인식할까?  
숫자 0,1 이미지가 입력으로 주어지면 출력값으로 입력의 숫자가 1일 확률을 내놓는다.
1일 확률만 출력해도 괜찮은 이유는 확률을 p라 했을 때 1-p가 0일 확률이 되기 때문이다.  

예를 들어 0 이미지가 주어지면 0.02값을 내놓는데, 이는 해당 이미지가 1일 확률이 2%이고, 0일 확률이 98%라는 뜻이다. 이때 일반적으로 확률이 0.5보다 크면 1로 분류하고 낮으면 0으로 분류하며, 이러한 분류를 위해 사용되는 방법이 logistic regression이다.

컴퓨터가 어떻게 이런 분류를 가능하게 하는지 알아보기 위해 logistic regression의 정의와 동작 방식에 대해 알아보고자 한다.

### Logistic Regression의 정의
logistic regression은 데이터가 어떤 카테고리에 속할지 확률을 추정하여 분류하는 기법으로, linear regression과 달리 양적 구분이 아닌 질적 구분을 할 때 유용한 기법이다.

예를 들어, 숫자 0과 1을 적절하게 분류하는 문제, 사진의 동물이 고양이인지 개인지 분류하는 문제 등 범주화를 다룰 때 유용하다.

### 동작 방식
선형 회귀 방식과 유사하게 특정 연산을 수행하는 노드의 연결을 통해 출력값을 만들어낸다.

다만, 선형 회귀와의 차이점이 있다면 선형 연산 결과(z = wx + b)를 0~1 사이의 값으로 도출하는 sigmoid = $1 / (1 + e^(-z))$를 사용한다는 점이다. 

입력값이 들어오면 선형연산을 통해 z 값을 만들고, 이 값은 sigmoid를 통해 0과 1사이 값을 도출한다. 만약 이미지가 1에 가까우면 sigmoid의 함수값은 1에 수렴하고, 0에 가까우면 0에 가깝게 수렴한다.

해당 과정을 통해 실제 정답값과 차이가 발생한 경우 오차율을 계산하여 다음 학습 때 더 적절한 가중치를 설정하게 된다.

예를 들어 실제 계산을 따라가보자면, 이미지는 모두 픽셀으로 이루어져있고, 이미지의 모든 픽셀값이 입력으로 주어진다. (이미지가 16*16 흑백 이미지라면, 256개의 픽셀값 존재) 

흑백 0 이미지가 아래처럼 생겼다면, 화살표 부분의 픽셀 값과 연산을 담당하게 된 가중치는 0을 검출하기 위해 높은 가중치를 가지게 된다.

```text
------------------- <-
| <-               | <-
| <-               | <-
| <-               | <-
| <-               | <-
| <-               | <-
| <-               | <-
------------------- <-
```

그러나, 가중치는 1을 나타내는 이미지가 들어왔을 때 1을 나타내는 픽셀값과 연산이 진행되는 가중치들에 대해서도 높은 가중치를 가져야한다.

1과 0을 적절하게 분류하는 가중치를 찾기 위해 반복 연산을 통해 가중치를 업데이트하고 이를 통해 잘 분류하는 가중치에 도달하게 된다.
