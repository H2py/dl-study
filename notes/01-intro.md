### 딥러닝의 정의
딥러닝이란 컴퓨터가 방대한 학습을 통해 자체적으로 판단할 수 있는 방법을 의미한다.
인간의 뇌를 모방하여 만든 신경망(Neural Network) 구조로 이루어져있다.

신경망은 신경망의 기본 단위인 뉴런이 방대하게 얽혀 있으며 한 뉴런이 계산기 역할을 수행한다.
뉴런은 입력(x)이 주어지면 가중치(w)를 곱하여 결괏값을 도출하는데, 이때 가중치는 입력의 '중요도'를 나타내는 지표라고 이해하면 된다.

### 딥러닝의 예시
예를 들어 '내일 피크닉을 가는 것이 좋을까?'라는 질문에 대한 판단을 딥러닝을 통해 내린다고 했을 때,
판단을 위한 지표(입력값 x)가 필요하다. 아래는 판단 지표에 따른 점수를 나타낸다.

1. 내일 날씨 정보 : 맑음, 흐림, 비(각각 1, 0, -1)
2. 같이 갈 친구 유무 : 있으면 1 아니면 0
3. 돗자리 대여 가능 유무 : 가능하면 1 아니면 0

피크닉을 갈 때 날씨는 매우 중요한 요소이기 때문에 날씨의 가중치(중요도)는 5, 친구 유무는 3, 돗자리 대여 유무는 1으로 설정해보자
전체 점수가 3를 넘기면 내일 피크닉을 갈 것이다.

내일 날씨가 흐리고, 친구가 없지만 돗자리 대여가 가능하다고 해보자
0(흐린 날씨) * 5(가중치) + 0(친구 없음) * 3(가중치) + 1(돗자리 대여 유무) * 1(가중치) = 1

3보다 낮은 값이 도출되었으므로, 날씨 흐림, 친구 x, 돗자리 대여 o일 시에는 피크닉을 가지 않는다.

## 아직 모르겠는 것
### ReLu 비선형성의 직관적인 의미
비선형 함수가 없는 경우 선형성만 표현 가능하기 때문에 표현에 제약이 생긴다는 것은 이해했으나,
ReLu 같은 함수를 추가한다고 하여, 어떻게 비선형성 표현이 가능한지 '직관적'으로 이해하지 못하였습니다.

ex. x <= 0 : 0, x > 0 : x라는 식이 어떻게 곡선, 휘어짐 등을 표현 가능한지?
개인적으로 생각하기로는 ReLU 함수를 통과하면 '꺾이는 부분'이 만들어지고 이 부분이 촘촘하게 모이면 '곡선'을 표현할 수 있다고 이해한 상태입니다.

i. 학습 데이터의 증가 ii. 컴퓨팅 연산 속도 증가 iii. 학습 알고리즘 성능 향상으로 인해 유의미한 성과를 도출.
## 2. 구조화 데이터와 비구조화 데이터의 차이는 무엇이며, 딥러닝이 특히 강점을 보이는 쪽은 어디인가.
구조화 데이터는 특정한 규칙에 따라 미리 분류가 된 데이터를 의미하고, 비구조화 데이터는 규칙을 찾기 어려운 데이터를 의미한다.
딥러닝은 비구조화 데이터를 다룰때에 강점이 있는데, 이유인 즉슨 딥러닝은 여러 패턴을 학습하여 일반적인 결론을 도출하는 귀납적 추론 방법을 사용하기 때문이다.
결론적으로, 미리 정해져 있는 패턴을 다룰 때에는 인간이 직접 그 절차를 제시하면 되지만 비구조화 데이터를 다룰 때에는 인간이 '어떤 패턴이 있는지' 알고리즘 형식으로 규정하기 어렵기 때문에 딥러닝을 사용한다.
## 3. ReLU가 sigmoid보다 학습이 빠른 이유는 무엇인가.
Gradient Descent를 이용하여 모델의 가중치를 학습하는데, 이때 derivative가 모델의 주요 학습 요인 중 하나이다.
sigmoid의 경우 입력값이 매우 크거나 작은 경우 derivative가 0에 수렴하는 값이 도출되기 때문에 가중치를 소폭 조정할 수 밖에 없게된다.

그러나, ReLU의 경우 입력값 x가 0보다 큰 경우 derivative가 1로 고정되어 나타내기 때문에 일반적인 경우에서 학습속도가 더 빠르다.
