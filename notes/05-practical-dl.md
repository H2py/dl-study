## Train / Dev / Test set 정의
딥러닝 모델을 최적화한다는 것은 모델의 구조나 데이터 변경 등을 통해 최적의 성능을 도출하는 일련의 과정을 진행한다는 것을 의미한다.

지금까지는 train set과 test set을 통해서 모델을 학습하고, 최종 정확도를 예측했지만 또 다른 데이터 유형인 dev set(validation set)을 사용해 모델의 최적의 구조 및 하이퍼파라미터를 찾을 수 있다.

Train set : 학습을 위해 사용되는 데이터
Dev set : 모델의 구조를 변경하기 위해 사용되는 데아터
Test set : 모델의 최종 성능을 확인하기 위한 데이터

보통 이들을 공부 / 모의고사 / 실제 시험에 비유하곤 한다.
train set을 통해서는 모델이 '학습'을 진행하며, dev set은 모의고사로 지금껏 학습한 내용이 적절한지, 공부 방법을 바꿔야하는지(ex. layer 수 변경, 하이퍼파라미터 조정 등등) 결정할 수 있다. test set은 실제 시험으로 최종 성능을 테스트할 때 쓰인다.

dev set은 train set이 아닌 test set과 같은 분포에서 추출된 데이터여야한다.
예를 들어 동물을 분류(개, 고양이, 호랑이 등등)하는 모델을 만들고 있는데 고양이에 관련한 train set이 모두 털이 있는 고양이를 사용했다고 가정해보자.

test set에서 털이 없는 고양이를 입력으로 사용하면 모델은 이를 털이 없는 다른 생물(ex. 쥐)로 인식하여 잘못 분류할 가능성이 있다.

이는 모델이 충분한 데이터를 가지고 학습을 하지 않아 발생했기 때문에 원인을 찾아서 해결해야한다.

모델의 원인을 찾는 과정에서 dev set을 이용해서 테스트를 진행하는데 dev set이 train set과 비슷하다면(털이 있는 고양이) 원인은 찾지 못한 채 성능이 좋다고 오인하게 된다.

따라서, test set의 분포와 비슷하게 dev set 분포를 설정해야한다.

## Bias & Variance
Bias(편향)은 사전적으로는 편향, 편견, 치우침 등을 의미한다.
따라서, 딥러닝 모델에서 Bias가 크다면 편향이 커서 모델이 학습을 제대로 진행하지 못한 경우를 일컫게 된다.

즉, 학습이 제대로 안되어 모델의 train / test error가 둘 다 모두 높은 경우를 의미한다.

반대로 Bias가 낮다는 것은 모델이 학습을 잘 진행할 수 있다고 평가한다.

Variance(분산)은 평균으로부터 얼마나 멀리 떨어져있는지를 나타내는 척도이다.
Variance가 높다는 것은 예측된 값과 실제값의 차이가 크다는 것을 의미하고 이는 곧 training 과정에서 train dataset에 과적합이 되어 발생한 결과라고 판단한다.

Bias가 높거나 Variance가 높은 경우 모델에 대한 진단이 달라져야한다.
Bias가 높은 경우 모델이 train dataset 조차 제대로 학습을 못했다는 것을 의미하기 때문에 모델의 구조를 변경하거나 iteration을 증가시킨다.

Variance가 높은 경우에는 더 많은 데이터셋을 확보하거나, 정규화를 진행해야한다.

## 정규화 : Regularization & Normalization
정규화는 Regularization 그리고, Normalization로 구분된다.
둘 다 모두 분산을 줄이기 위한 기법이며 Regularization은 Frobenius norm, drop out, data augmentation 그리고 early stopping 등이 있다.

Normalization은 input을 (input - 평균) / 표준편차로 재가공하여, 평균은 0이고 분산은 1인 데이터를 사용하는 기법이다.
### Regularization
첫번째로 L2, L1 regularization은 weight 행렬의 norm을 loss function 식에 추가하여 높은 가중치에 대해서도 패널티를 부과하는 방식이다.

보통, L2 regularization을 쓰기 때문에 이를 기준으로 설명한다.
$$ \|W\|_F = \sqrt{\sum_{i=1}^{m} \sum_{j=1}^{n} w_{ij}^2} $$


$$ W = \begin{bmatrix} 1 & 3 \\ -2 & 4 \end{bmatrix} $$

$$ \|W\|_F = \sqrt{1^2 + 3^2 + (-2)^2 + 4^2} = \sqrt{1 + 9 + 4 + 16} = \sqrt{30} \approx 5.48 $$

이처럼 2*2 행렬이 존재할 때, element wise하게 L2 norm을 만드는 수식이다.

이를 람다 하이퍼파라미터를 곱한 뒤, 이전 layer의 node 수 * 2로 나누어 손실식을 완성한다.

$$ L = L_0 + \frac{\lambda}{2n_{in}} \|W\|_F^2 $$

높은 값을 가진 가중치에 패널티를 부과하면, 하나의 레이어를 거쳐갈때마다 '안정화 된 값'을 출력하기 때문에 학습과정에서 모델이 과적합을 줄일 수 있다.

이는 tanh를 예시로 들어서 설명하면 좋은데, weight 정규화를 통해 값이 0에 가까운 값을 도출하면 최종 출력되는 값은 선형성을 가지게 된다.

이에 따라서, 불필요한 미세한 분류가 선형으로 바뀌면서 삐뚤빼뚤한 형태가 아닌 좀 더 완만한 곡선의 형태를 띄게 된다.

relu도 마찬가지로 출력값이 완화가 되어 불필요하게 세밀한 분류를 하지 않아 overfitting이 완화된다.

---
두번째로, dropout이 존재한다.
dropout은 특정 레이어가 랜덤하게 노드를 유지하여 가중치가 높은 노드의 의존을 방지하는 학습 기법이다.

특정 노드에 의존하게 되면 학습 과정이 불안정해진다는 단점이 존재한다.
이유인 즉슨, 특정 노드가 training 입력의 특징을 통암기하여 외운 뒤 '이 특징만 보이면 고양이일거야!'와 같은 출력을 내보내는 것이기 때문이다.

따라서, 특정 노드에 의존한다는 것은 곧 training set의 지엽적인 특징을 보고 확신값을 크게 출력한다는 것(overfitting)이므로 입력값의 여러 특징을 두루학습하여 처음 보는 데이터셋에 대해서도 robust한 출력이 가능하도록 만들어야한다.

예를 들어 하나의 노드에 연결된 가중치가 너무 크다면 기울기를 업데이트 하는 과정에서 큰 폭으로 업데이트를 하게 되며 이 과정에서 손실이 크게 튀거나 진동한다. 즉, 손실이 단조 감소하는 것이 아닌 예측하기 어려운 경향을 보일 수 있다.

세번째로는 data augmentation이다.
과적합을 해소하기 위한 방법 중 하나는 데이터를 많이 확보하는 것이다.
그러나, 대부분의 산업 현장에서 데이터는 항상 부족하게 마련되기 때문에 하나의 데이터를 찌그러뜨리고, 회전하거나, 왜곡, 크기 보정 등을 통해 데이터의 여러 방면을 학습하게 만든다.

다만, 데이터를 180도 회전하는 조치는 취하지 않는다.
동물을 분류하는 모델을 만드는데 동물의 발이 천장을 향하는 사진을 입력으로 받을 일은 없기 때문이다.

마지막으로는 early stopping이다.
test loss가 감소하다가 증가하는 지점이 과적합이 시작되는 지점이다.
이때, 과적합의 초입인데도 불구하고 train을 계속 진행하면 weight의 과적합은 더욱 가중되기 때문에 경향을 보이는 지점에서 학습을 멈추는 것이다.

다만, test set을 통해 과적합의 지점을 확인할 수는 없으니 dev set으로 이 경향을 확인한다.

### Normalization
Normalization은 초기 입력값, 초기 파라미터 등을 올바르게 설정하여 모델의 성능을 최적화하는 과정이다.

첫번째로 입력값 normalization은 입력값을 평균은 0, 분산은 1인 데이터로 맞추는 과정을 의미한다. 수식으로 나타내면 아래와 같다.

$$z = \frac{x - \mu}{\sigma}$$

특성 1의 데이터 분포가 0~1e10이고
특성 2의 데이터 분포가 0~1이면

가중치가 0.1일때, 특성 1과 특성2가 만드는 출력값의 차이는 매우크다.
이로인해 특정 가중치의 기울기가 매우 크게 형성되어 한쪽 특성의 등고선이 한쪽 축으로 길게 찌그러진 형태를 만들게 된다.

이 경우, 경사하강법을 사용할 때 learning rate를 매우 작은 값을 설정하여 이 좁은 벽 사이에서 진동을 하며 나아가는 것을 방지해야하고
학습이 매우 느리게 진행된다.

따라서, 입력 정규화 과정을 통해 contour map이 균일하게 설정되도록 만든다.

두번째로는 가중치 초기화 기법이다.  
특히, ReLU 곡선을 다룰 때 사용하는 he 초기화법에 대해 알아본다.

기존에는 가중치 초기화 시, np.random.randn(...) * (상수)라는 수식을 사용하여 초기화를 했다면, He 초기화에서는 상수 값을 np.sqrt(2/layers_dims[l-1])을 사용하여 가중치를 설정하는 방법을 사용한다.  
도출 배경은 아래와 같다.

입력 정규화가 완료되면 평균은 0, 분산은 1인 데이터가 형성된다.

입력뿐만 아니라, 중간에 형성되는 데이터 또한 평균은 0이고, 분산은 1을 유지해야 학습이 원활하게 진행될 수 있다.

따라서, 다음 식이 성립해야한다.

Var(z) = n * Var(w) = 1 (n은 입력의 개수)

Var(w) = 1/n이 되면 Var(z) = 1이 되어, 분산 = 1을 만족한다.
공식에 따라, Var(w)에 1/n을 곱하기 위해서는 w에는 np.sqrt(1/layers_dims[l-1])을 곱해야하므로

가중치에는 표준편차인 np.sqrt(1/layers_dims[l-1])을 곱해야한다.

이때, ReLU 관점에서 보면 절반은 음수이고, 절반은 양수이며 절반인 값들은 다음 층으로 전달이 되지 않기 때문에 애초에 2를 곱하여 사라지는 값에 대한 보상값을 설정한다. 즉, 분산은 2/layers_dims[l-1]이 된다.

표준편차는 np.sqrt(2/layers_dims[l-1])이 된다.
